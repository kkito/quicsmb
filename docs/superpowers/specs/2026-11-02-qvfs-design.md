# qvfs 设计文档（FUSE 原生盘 + QUIC 块传输 + 分层缓存 + 回写）

日期：2026-11-02｜状态：用户已逐节确认，待评审 spec 后进 writing-plans

## 1. 背景与目标

两台机器：VPS（server，固定公网 IP，20G 缓存盘，跑 FUSE 对本地程序暴露原生盘）
+ 家里主机（client，10T 大盘，跑自研 daemon）。QUIC 双向传输，可靠性由 QUIC
保证，自研集中在认证、分块、缓存、回写、FUSE、面板。传输底座复用 quicsmb 现有
quic-go 代码与 mytun 风格 Web 面板模式。

非目标：强实时一致性、HA/多副本、多租户、Windows 盘符。

## 2. 架构

```text
VPS (server)                                    家里 (client, 主动拨出)
┌─────────────────────────────┐                  ┌──────────────────────────┐
│ qvps daemon                 │   QUIC           │ qhome daemon             │
│ ┌──────┐ ┌──────────────┐   │   ALPN=qvfs/1    │ ┌────────┐ ┌────────────┐ │
│ │ FUSE │→│ chunk cache  │←──┼────────────────→ │ │ daemon │→│ 10T 大盘   │ │
│ │挂载点 │ │LRU+配额+脏块 │   │   Key认证+黑洞    │ │        │ │(本地文件)  │ │
│ └──────┘ │ 元数据落盘   │   │                  │ └────────┘ └────────────┘ │
│ ┌──────┐ └──────────────┘   │                  └──────────────────────────┘
│ │ 回写 │  凌晨02-03点+满72h 按块推送
│ │ 调度 │
│ └──────┘
│ ┌──────┐  Web面板 :8080（状态/缓存/热度/流量/IO/参数热更新）
│ │ web  │
│ └──────┘
└─────────────────────────────┘
```

- FUSE 只在 Linux（VPS）上，go-fuse；家里 daemon 只做块↔文件读写 + QUIC client。
- 回源与回写都由 VPS 发起请求、家里响应；家里无公网 IP 也可工作。
- 写入：Write-back + 脏块元数据持久化（重启可恢复回写任务）。

## 3. 数据模型与核心流程

- 块寻址：`ChunkID = {FileKey, Index}`，块大小启动时一次性确定（默认 512KB），
  不可热改。重启时参数与元数据记录不一致则拒绝启动；想改=停机清空缓存后重启。
  面板中块大小只读显示。
- 块状态机：`CLEAN → DIRTY → SYNCING → CLEAN`；回源 Miss 时
  `ABSENT → FETCHING → CLEAN`。脏块元数据（id + 脏时间 + 校验和）落 VPS 磁盘。
- 读：FUSE → 缓存命中返回（热度+1）→ 未命中经 QUIC 向家里要块 → 写缓存（LRU）→ 返回。
- 写：FUSE → 写缓存块 → 标 DIRTY + 脏时间 → 立即返回。
- 回写：调度器每分钟扫脏块，`now - dirtyTime ≥ 72h` 且在 02:00–03:00 窗口内 →
  按块 QUIC 推送 → 家里落盘回 ACK → 标 CLEAN。窗口外/失败则重试计数+1，下窗口继续。
- 认证：QUIC 建连首帧 `HMAC(key, nonce)`，VPS 校验失败直接丢弃连接、零回包（黑洞）。
  key 经配置文件下发，支持热更新。

## 4. 模块拆分（internal/ 七包）

| 包 | 职责 | 单测方式 |
|---|---|---|
| `chunk` | 偏移↔块号映射、切分、校验和（纯函数） | 表测 |
| `cache` | LRU + 配额淘汰 + 命中率 + 热度计数 | 内存 fake 后端 |
| `metastore` | 脏块元数据落盘/恢复、块大小校验 | `t.TempDir()` 真文件 |
| `auth` | HMAC 构造/校验、黑洞判定 | 纯函数 + fake conn 零写入断言 |
| `xfer` | 块请求/响应编解码、重试/断点续传状态机 | fake QUIC stream 双向 pump |
| `writeback` | 调度判定：满 72h + 窗口内 + 失败重试 | 可注入时钟，表测 |
| `web` | 状态/缓存/热度/流量/IO + 参数热更新 | fake manager（mytun 模式） |

`fuse` 层与家里 `disk` 落盘层保持最薄（翻译+透传）。FUSE 本体不做单测，靠 e2e 回环。
覆盖率目标：七包行覆盖 ≥80%，`chunk`/`auth`/`writeback` ≥95%。
可热更新参数：回写延时、回写窗口、缓存配额、Key。块大小不可热改。

## 5. 一致性与错误处理

- 弱一致：脏块 72h 内版本差允许；并发写同一块 = last-writer-wins，无文件锁
  （写进 README 与面板提示）。
- 回源失败 → FUSE 读返回 EIO（不返回半块/旧版冒充）。
- 回写失败 → 脏块保留 + 重试计数，下窗口继续。
- QUIC 断连 → 家里按退避重拨（1s/2s/4s…上限 5min）。
- VPS 重启 → 脏块元数据 + 缓存块均在盘上，直接恢复。

## 6. 验收映射

- 原生盘读写 → `make e2e`（挂载 tmpfs FUSE + 读写对比）。
- 5G/10G 大文件可靠传输+断点续传 → `xfer` 单测 + e2e 大文件 roundtrip。
- LRU 不撑爆 → `cache` 配额边界单测 + e2e 灌配额上限验证。
- 72h+凌晨回写 → `writeback` 注入时钟单测 + e2e 调小参数验证。
- 黑洞认证 → `auth` 零回包单测 + e2e 真连验证无响应。
- 面板 → `web` 单测 + 人工看板。
